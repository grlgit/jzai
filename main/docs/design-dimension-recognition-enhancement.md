# 图纸尺寸识别增强设计

## 问题分析

### 当前架构
```
drawing_parse_pdf (规则提取)
    ↓
125个原始尺寸 (纯文本+坐标)
    ↓
Agent LLM 过滤
    ↓
~60个检验项目 (50%遗漏率)
```

### 遗漏原因分析

1. **规则提取保守**
   - `isDimensionText()` 使用严格模式匹配
   - 可能漏掉非标准格式的尺寸文本
   - 例如：配合代号 (H7, k6)、形位公差等

2. **LLM 缺少视觉上下文**
   - 只有文本坐标，没有图形信息
   - 无法判断尺寸线指向哪个特征
   - 缺少图纸的整体布局理解

3. **符号识别不完整**
   - 工程符号：⊥ (垂直度), ∠ (角度), ⌒ (弧), ⚪ (同轴度)
   - 形位公差：▭ (平面度), ◯ (圆度), 三 (位置度)
   - 配合符号：H7, k6, JS7 等

4. **语义理解不足**
   - LLM 不知道哪些是关键尺寸
   - 无法区分参考尺寸与检验尺寸
   - 缺少工程制图标准知识

## 增强方案

### 方案 A：LLM 辅助提取 (推荐)

#### 设计思路
在解析阶段引入 LLM，对每个文本项进行分类：

```
PDF → 提取所有文本 → LLM 分类 → 尺寸标注
                     ↓
                非尺寸文本 (过滤)
```

#### 实施步骤

1. **新增工具: `drawing_parse_pdf_with_llm`**
   - 先用规则提取所有候选文本
   - 调用 LLM 对每个文本分类: `DIMENSION | NON_DIMENSION`
   - 返回 LLM 分类结果 + 置信度

2. **增强提示词**
   - 提供工程符号参考表
   - Few-shot 示例
   - 尺寸标注特征说明

3. **返回结构增强**
   ```json
   {
     "dimensions": [...],
     "candidates": [
       {
         "text": "H7",
         "position": {x, y},
         "llmClassification": "DIMENSION",
         "confidence": 0.9,
         "reasoning": "配合代号，常与孔径配合出现"
       }
     ]
   }
   ```

#### 优势
- 利用 LLM 的语义理解能力
- 对每个文本项给出明确分类理由
- 可以调整置信度阈值

### 方案 B：视觉辅助识别

#### 设计思路
结合 PDF 视觉信息进行识别：

```
PDF → 页面截图 → 视觉模型识别
              ↓
        文本位置关联 → 尺寸标注
```

#### 实施步骤

1. **PDF 页面转图像**
   - 使用 pdf.js 渲染第一页为 PNG

2. **视觉模型分析**
   - 识别尺寸线、箭头、引线
   - 识别工程符号
   - 标注区域识别

3. **多模态融合**
   - 文本位置 + 视觉特征
   - 判断是否为尺寸标注

#### 优势
- 利用视觉模型的图形识别能力
- 可以识别尺寸线和引线
- 更符合人工识图方式

### 方案 C：两阶段 LLM 协作

#### 设计思路
解析和过滤两个阶段都用 LLM，但分工明确：

```
阶段1: 解析 LLM
  → 任务: 对每个文本项分类 (尺寸 vs 非尺寸)
  → 输入: 文本内容 + 位置上下文

阶段2: 过滤 LLM (当前 Agent)
  → 任务: 从尺寸中筛选检验项目
  → 输入: 尺寸数据 + 工程知识
```

#### 实施步骤

1. **解析阶段增加 LLM 分类器**
   - 轻量级专用 LLM
   - 快速二分类任务
   - 高置信度才输出

2. **过滤阶段增强提示词**
   - 提供图纸类型知识
   - 常见检验项目模式
   - 参考尺寸特征

#### 优势
- 两个 LLM 各司其职，提高准确率
- 解析 LLM 专注分类，过滤 LLM 专注工程判断

### 方案 D：知识库增强

#### 设计思路
构建工程制图符号知识库，辅助 LLM 理解：

```
知识库 → 尺寸符号手册
    ↓
LLM 提示词注入 → 增强识别
```

#### 实施步骤

1. **构建知识库**
   ```
   - 基础尺寸符号: ⌀, R, ∠, °
   - 形位公差: ⊥, ∥, ⌒, ▭, ◯
   - 配合代号: H7, k6, JS7, h7
   - 表面粗糙度: Ra, Rz
   - 焊接符号: 焊缝类型
   ```

2. **知识注入方式**
   - System prompt
   - Function calling 时的参数说明
   - Few-shot 示例

## 技术细节

### 工程符号参考表

| 类别 | 符号 | 说明 | 示例 |
|------|------|------|------|
| 直径 | ⌀ φ Φ | 直径标注 | ⌀50±0.1 |
| 半径 | R | 半径标注 | R10 |
| 角度 | ∠ ° | 角度标注 | 45°±1° |
| 垂直度 | ⊥ | 形位公差 | ⊥0.05 |
| 平行度 | ∥ | 形位公差 | ∥0.1 |
| 平面度 | ▭ | 形位公差 | ▭0.02 |
| 圆度 | ◯ | 形位公差 | ◯0.01 |
| 位置度 | ⌖ | 形位公差 | ⌖0.05 A B |
| 弧/曲线 | ⌒ | 弧长标注 | ⌒50 |
| 配合 | H7, k6 | 孔轴配合 | ⌀50H7/k6 |

### 尺寸标注特征

1. **有数字**: 通常包含数值
2. **有单位**: mm (默认), ° (角度)
3. **有公差**: ±, +0.1/-0.2, H7, JS7
4. **有符号**: ⌀, R, ∠, °
5. **有标注线**: 尺寸线、引线 (视觉特征)

### 非尺寸特征

1. **图号信息**: 图号、零件号、编号
2. **标题栏**: 数量、比例、日期
3. **技术要求**: "未注公差", "表面处理"
4. **零件列表**: 序号、名称、数量
