## 概述

LC.LUK.ST.001（Rev. No: 1，2021年6月1日）是 LC Waikiki 的纸箱包装与标签标准，定义了产品从包装到运输全过程的规范要求。[^1]

## 关键定义

| 术语 | 定义 |
|------|------|
| Polybag（PP） | 用于单独包装产品的塑料袋 |
| Blister Bag（PE） | 用于包装已单独包装的多种搭配产品的袋子 |
| Carton Box Bag（PE） | 放置已装入Polybag的未经搭配产品的袋子 |
| Unassorted Quantity | 一个产品的每种颜色各一个尺码 |
| Assortment | 产品的尺码分布（如 S/1, M/2, L/2, XL/1） |
| Lot | 一个包装好的搭配组合 |
| EAN13 | 3位数字（12位+1位校验码）条码编码标准 |

## 纸箱内容标准

- 同一Lot内的产品应整齐堆叠，每个Lot袋（PE）上附有Lot标签
- Lot标签为热敏标签，尺寸：高10cm，宽15cm
- Lot标签条码必须包含：订单号、特殊代码、尺码分布、Lot编号
- Lot袋口用4.5cm宽透明胶带垂直贴两条（边缘）+水平贴一条
- 箱内所有产品必须挂有价格吊牌，条码ID必须可见
- 未经搭配的配饰产品（含袜子）须单独装袋，标签朝外
- 产品价格吊牌、内部条码标签、Lot标签、纸箱条码标签的信息必须一致
- 条码编码系统必须使用EAN13

## 聚袋标准

- Polybag（PP）质量：7-micron聚丙烯
- Blister Bag（PE）质量：双层10-micron厚，最大公差1micron
- PE和PP袋不得含有BHT（丁基羟基甲苯）
- 安全警告必须印在Polybag背面（与胶带同侧）

## 纸箱标准

### 储存建议
- 相对湿度50%-70%环境下储存
- 纸箱不得直接放置地面，不得水平堆叠

### 纸箱规格
- 纸箱质量：K/F/F/F/K Kraft和Fluting纸，125 g/m2
- 属性：C+B双波楞
- 满载纸箱最大重量：20kg（超重拒收）
- 纸箱必须粘合接缝
- 包装后箱内不得有空隙
- 多Lot款式，1个Lot高度不得超过14cm（金属检测桥高度）

### 尺寸规格
- 未经搭配混合纸箱尺寸：58 x 38 x 20cm（宽x长x高）
- 纸箱尺寸采用外到外测量（out-to-out）
- 纸箱两侧长面右下角须有70x100mm黑线框（水平30mm，垂直50mm偏移）

### 纸箱短侧标签
- 外部纸箱标签不得为热敏标签
- 标签须可被条码扫描器扫描，不得擦除、磨损或复印
- 纸箱短侧标签尺寸：高10cm，长15cm
- 标签须贴于纸箱两个短侧面的中央
