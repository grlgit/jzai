## 概述

ST 203-03（Rev. No: 2，2014年8月26日）是 LC Waikiki 的测量方法指南（How to Measure Guidelines），由技术总监部发布。[^1]

## 测量编码系统

| 编码示例 | 含义 |
|---------|------|
| W05 | 胸围宽度（Chest Width） |
| W06@ | 前幅宽度（Across Front），@表示距肩最高点的厘米数 |

- 每个代码在不同品类上表示相同测量位置
- 例如W05可用于衬衫、夹克、T恤等不同品类

## 测量基本规则

1. 产品放在未被布料覆盖的平整表面上测量
2. 测量时产品不得悬挂在测量台边缘
3. 不得拉扯、移动、拉伸产品
4. 必须从使用校准卷尺的品牌采购测量工具
5. 如有疑问，通过图片向工厂展示正确测量方法

## 测量品类覆盖

| 品类 | 涵盖范围 |
|------|---------|
| 衬衫（Shirts） | 男/女/童衬衫 |
| 裤装（Pants） | 各类长裤、短裤 |
| 裙装（Skirts） | 各类裙子 |
| 夹克（Jackets） | 各类夹克 |
| 外衣（Outerwear） | 外套、大衣等 |
| 连体装（Overall） | 连体裤/裙 |
| 针织品（Knit） | 针织类服装 |
| T恤/Polo/抓绒 | 针织上装 |
| 背心/吊带 | 无袖上装 |
| 内衣/泳装 | 内衣、比基尼、泳装 |

[^1]: ST 203-03_Olcum Yerleri-How to Measure.pdf
