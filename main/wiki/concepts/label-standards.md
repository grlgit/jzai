## 概述

LC Waikiki 针对不同面料类型分别制定了标签附着标准：ST 204（梭织品）和 ST 206（针织品），均发布于2010年，版权归 Tema Magazacilik Hiz. Tic. A.S. 所有。[^1][^2]

## 品牌标签附着方法

### 通用附着方式

| 附着方式 | 说明 |
|---------|------|
| 侧折式品牌标签 | 对称置于后中两侧，与领缝一起缝合 |
| 底折式品牌标签 | 对称置于后中两侧，与领缝/腰缝一起缝合 |
| 蝴蝶式品牌标签 | 对称置于后中两侧，两侧与领缝一起缝合 |
| 旗帜标签 | 折叠线为标签中线，缝份根据标签位置调整 |

### 梭织品（ST 204）特殊要求

- 男/童裤装：品牌标签位于内腰后中（C.B.），四周缝合不外露
- 男裤带logo内腰：品牌标签位于左前腰缝，距侧缝6cm
- 男童衬衫：品牌标签位于内后过肩，距领缝2.5cm下方
- 可反穿夹克/外套/背心：品牌标签在右口袋开口内，洗标在左口袋开口内
- 男士衬衫尺寸标签：左肩/领缝处

### 针织品（ST 206）特殊要求

- **带领款式**：品牌标签对称后中两侧，内领缝，两针水平线同色
- **罗纹领款式（拷克缝）**：对称后中两侧，内拷克缝
- **内领包边款式**：对称后中两侧，内包边处
- **后领半月片款式**：对称后中两侧，距领缝2-3cm下方
- **裤子**：对称后中两侧，内拷克缝处

## 条码标签与洗标

### 条码标签
- 每种颜色和每种尺码使用不同的条码标签
- 必须始终置于洗标之上

### 洗标（护理标签）附着位置

| 品类 | 位置 |
|------|------|
| 衬衫/上装（梭织） | 左内侧缝，距下摆：婴童4-5cm / 少年7cm / 成人10cm |
| 上装（针织） | 左内侧缝 |
| 男/童衬衫 | 左内侧缝，距下摆：1-4岁7cm / 5-16岁8cm |
| 裤装/裙装 | 腰头内侧，距腰缝：儿童4-5cm / 少年7cm / 成人10cm |
| 内衣 | 背部外侧 |

## 吊牌与备用扣

- **有钮扣款式**：吊牌挂于扣眼处
- **有按扣款式**：吊牌挂于按扣处
- **男/童衬衫**：吊牌挂于品牌标签或拉链头处
- **备用扣**：附着于洗标或品牌标签附近

## 徽章/标签/织带缝合方式

| 方式 | 说明 |
|------|------|
| 四边缝合 | 面线色匹配标签，底线色匹配面料 |
| 两侧缝合（可折叠） | 面线色匹配标签，底线色匹配面料 |
| 上下边缘缝合（可折叠） | 面线色匹配标签，底线色匹配面料 |

[^1]: ST 204_Label Attachment Standards for Apparel Products Made of Woven Fabric.pdf
[^2]: ST 206_Label Attachment Standards for Apparel Products Made of Jersey Fabric.pdf
