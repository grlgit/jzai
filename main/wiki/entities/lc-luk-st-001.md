# LC.LUK.ST.001 - 纸箱包装与标签标准

**修订版**：Rev.1，2021年6月1日  
**发布部门**：Mağazacılık Süreç İyileştirme（零售流程改善）[^1]

---

## 概述

本标准规定了 LC Waikiki 产品从内包装到外箱的全链条包装和标签要求，包括定义、纸箱内容标准、Polybag 标准、纸箱标准、封箱胶带、外箱标签和空运包装等。

## 核心参数

| 参数 | 数值 |
|------|------|
| Polybag 厚度 | PP 7微米 |
| Blister Bag 厚度 | PE 双层10微米（公差±1微米） |
| 纸箱材质 | K/F/F/F/K, 125g/m², C+B双瓦楞 |
| 标准箱尺寸 | 58 × 38 × 20 cm |
| 重量上限 | **20 kg** |
| MFC 框 | 70 × 100 mm |
| 外箱标签 | 10 × 15 cm |
| Lot 标签 | 10 × 15 cm，热敏 |
| 条码标准 | **EAN13** |

## 关键定义

| 术语 | 定义 |
|------|------|
| **Unassorted Quantity** | 每个颜色各一个尺码 |
| **Assortment** | 产品的尺码分布（如 S/1, M/2, L/2, XL/1） |
| **Lot** | 包装好的一个搭配组 |
| **Unassorted Carton** | 仅包含未混搭产品的纸箱（如30件同款同色同尺码） |
| **Single Lot** | 一箱只装一个 Lot |
| **Multiple Lot** | 一箱装两个以上 Lot |
