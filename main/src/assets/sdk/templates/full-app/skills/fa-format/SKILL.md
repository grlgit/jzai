# 笔记整理规范（fa-format）

当用户要求"整理笔记 / 汇总备忘"时，按以下格式输出：

## 输出格式

```markdown
# 备忘清单（YYYY-MM-DD）

## <主题分组标题>
- [ ] **标题** — 内容一句话摘要（创建日期）
```

## 规则

1. 先按主题把笔记分组（如：工作 / 生活 / 待办）；无法归类的进"其他"组。
2. 每条一行：复选框 + 加粗标题 + 破折号 + 一句话摘要 + 括号内日期。
3. 内容含"已完成/搞定"等字样的，复选框改为 `[x]`。
4. 组内按创建日期倒序；全文不超过 40 条，超出时保留最近 40 条并注明省略数量。
5. 只输出清单本身与一句总结，不复述原始内容全文。

本 skill 无 handler：纯提示规范，agent 读取后遵循即可。
